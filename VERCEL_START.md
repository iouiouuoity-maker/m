# ErrorMap V8 — GitHub + Vercel

Новая версия оформлена в стиле указанного образца TilLab: светлый фон, розово-мятный градиент, прозрачные карточки, анимированная гранёная фигура, переключатель «Оқушы / Мұғалім» и гостевой вход на главной. Название, учебный контент и авторство ErrorMap сохранены.

## Как устроено

**GitHub хранит код → Vercel публикует сайт → PostgreSQL хранит кабинеты и результаты.**

Один GitHub Pages публикует внешний вид и самостоятельные упражнения. Личные кабинеты с общей базой работают через API и требуют серверного размещения. Этот проект подготовлен для Vercel Python Functions. Фоновый Python-сервер для Vercel не запускается; точка входа — `api/index.py`.

## Настройки проекта Vercel

Импортируется корневая папка репозитория: там, где лежат `vercel.json`, `api`, `dist`, `server` и `requirements.txt`. Не выбирайте `dist` как Root Directory: иначе серверные функции не попадут в проект.

- Framework Preset: **Other**.
- Build Command: берётся из `vercel.json`: `python3 scripts/build_vercel.py`.
- Output Directory: **public**.
- Deploy after push: включён через обычное подключение GitHub к Vercel.

Скрипт сборки копирует только `dist` в публичную папку. Исходный сервер, база, `.env` и ключи не попадают в статическую выдачу.

## Постоянная база

В Vercel Marketplace подключается PostgreSQL, например Neon. Используйте pooled TLS connection URL провайдера в переменной `DATABASE_URL`. Приложение создаёт свои таблицы при первом обращении к API. Старая локальная SQLite-база автоматически не переносится.

Не используйте SQLite в `/tmp` для опубликованных кабинетов: это временный диск, и данные исчезнут. Если `DATABASE_URL` отсутствует, API этой версии возвращает понятный статус 503 и **не создаёт временную базу взамен постоянной**. Гостевые учебные инструменты доступны отдельно.

Обязательные переменные окружения Vercel:

```dotenv
DATABASE_URL=your-provider-pooled-postgres-url
ERRORMAP_SETUP_TOKEN=choose-a-long-random-setup-token
ERRORMAP_SECURE_COOKIE=1
CRON_SECRET=choose-another-long-random-value
```

`ERRORMAP_SETUP_TOKEN` нужен только для первоначальной регистрации учителя. Введите его на отдельной странице **Мұғалім → Мұғалімді тіркеу**. После создания первого учителя публичная регистрация учителей закрывается. Не отправляйте настоящие пароли и ключи в чат или GitHub.

На стандартном домене Vercel `ERRORMAP_ORIGIN` можно не задавать: сервер сверяет Origin с Host. При собственном домене задайте точный HTTPS origin без конечного слеша.

## Email позже

Адрес получателя добавляется в настройках учителя. SMTP настраивается секретными переменными `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`, `SMTP_USER`, `SMTP_PASSWORD`; `SMTP_SSL=1` для implicit TLS, иначе STARTTLS. Подтвердите у своего SMTP-провайдера, что его соединения доступны из Vercel; реальная доставка требует отдельной проверки.

Результат фиксируется независимо от доступности почты. Очередь хранится в PostgreSQL. Сервер пытается отправить одно письмо после сдачи/сохранения email/нажатия повторной отправки. Защищённый ежедневный маршрут `/api/mail/cron` обрабатывает ещё одно письмо; расписание `05:00 UTC`. Это базовый ограниченный worker: для большой накопленной очереди нужен более частый внешний планировщик или адаптация расписания под тариф. Один запрос ограничен по времени; результат сдачи не должен зависеть от большой рассылки. Повтор успешных писем не выполняется; lease препятствует одновременной обработке одного письма несколькими функциями, но абсолютная exactly-once доставка не заявляется.

## Проверка

```sh
node tests/check.cjs
node tests/experience_test.cjs
python3 tests/classroom_test.py
python3 tests/vercel_test.py
```

Проверены локальный учебный цикл, SQLite-API, роли/классы, очередь с тестовым SMTP, отображение карты, отсутствие временной базы в Vercel-обработчике и SQL-преобразования. В браузере просмотрены главная, переключение роли, языка и открытие гостевого режима. **Живой PostgreSQL, реальная сборка в аккаунте Vercel и доставка email пока не проверены: аккаунт и база не подключены.** Не считайте архив уже опубликованным сайтом.

Для локальной полной версии остаётся `python3 server/start.py` (без DATABASE_URL использует SQLite). Для простого просмотра дизайна — `dist/index.html`; логин на file:// не работает. Гостевая практика хранится в браузере и не синхронизируется с серверными результатами класса.
